What are we testing this round?

User research plan: Active eVED mileage Direct Debit at point of transaction

Research round focus

The focus of this round of testing is the active Direct Debit (DD) on eVED mileage in force at point of transaction scenario.

  • In scope: Credit journey only
  • Out of scope: Debt journey (reserved for a later round)

Scenario framing

To ground the research, the testing scenario is set at the midpoint of the transaction:

  • The Direct Debit has 6 months remaining.
  • The user has paid 6 months of eVED (with 6 months remaining).

Research objectives

We need to test user understanding across four key areas of the user interface.

1. Direct Debit component clarity
Does the user understand the information displayed on the page, specifically within the Direct Debit component box?
2. Terminology and value comprehension
Does the user understand active Direct Debit terminology? Is it clear how many miles are still to be collected or purchased?
3. Cost breakdown
Does the user understand the displayed values? Is the split between these values clear?
4. Component placement
The 'Paid for mileage' information has moved and is no longer in a dropdown menu. Do users find, read, and understand this content in its new location?
