What are we testing this round?

Research and testing objectives round 2: Vehicle tax liability

Vehicle tax and registration details

We need to understand how users navigate unexpected journeys ("unhappy paths"). This includes finding out how they respond when:

  • A vehicle tax liability renewal or expiry date is incorrect
  • The vehicle details they enter do not match official records

Pricing clarity

We need to evaluate if the price structures and example costs on the start page are clear and easy for users to understand.

Payment states

We must test both the 'in credit' and 'in debit' user journeys to ensure users understand their financial balance.

Mileage summary data

We need to observe how users read, interpret, and act on the mileage summary. Testing will help us determine if we need to restructure the data or separate it into different groups.

User journeys for unexpected errors (unhappy paths)

Incorrect vehicle details

The user enters a registration number (number plate) and V5C logbook reference number that do not match DVLA records.

Expired tax liability

The user enters details for an untaxed vehicle where the date of liability has already passed.

Near expiry tax liability

The user enters details for a vehicle where the date of liability is close to expiring.
